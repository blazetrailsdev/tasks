## Context

`generateConcreteAttributeMethods`
(`packages/activerecord/src/attribute-methods.ts`) installs attribute accessors,
`*BeforeTypeCast` and `*ForDatabase` readers directly onto the class prototype,
and carries its own `id` skip and ignored-columns handling. Rails has no such
method: `define_attribute_methods` (`attribute_methods.rb:104-125`) calls
`super(attribute_names)`, and every accessor is generated by
`define_attribute_method_pattern` (`activemodel/attribute_methods.rb:318-347`)
through the `define_method_#{proxy_target}` hooks — `Read#define_method_attribute`
(`attribute_methods/read.rb:11-22`), `Write#define_method_attribute=`
(`write.rb:15-26`), and the suffix patterns `BeforeTypeCast` / `Query` /
`Dirty` register.

PR #6717 made the bare pattern generate through those hooks, so trails now has
**two** generation paths that must agree: the hooks, and this bespoke one. They
already diverged once — the `id` skip existed only in the bespoke path, and
routing generation through the hooks reintroduced an `id` accessor over
`PrimaryKey#id`/`#id=` (`primary_key.rb:18-30`) until the real Rails guard
(`ID_ATTRIBUTE_METHODS`, `primary_key.rb:66-71`) was ported in that PR.

## Converged shape

Delete `generateConcreteAttributeMethods`; let `define_attribute_methods` call
the ActiveModel implementation over `attributeNames`, so every accessor —
reader, writer, `*BeforeTypeCast`, `*ForDatabase` — comes from the pattern
machinery under the generator's namespace, as it does in Rails. The
ignored-columns behaviour becomes what Rails already does: an ignored column is
absent from `attribute_names`, so no pattern ever names it.

## Acceptance criteria

- [ ] `generateConcreteAttributeMethods` is gone; AR's `define_attribute_methods`
      mirrors `attribute_methods.rb:104-125`.
- [ ] The `*BeforeTypeCast` / `*ForDatabase` readers come from their suffix
      patterns rather than being installed inline.
- [ ] Ignored columns generate no accessor because they are not in
      `attributeNames`, not because a loop skips them.
- [ ] The AR attribute-methods, attributes, base, dirty, inheritance and
      associations suites pass on all three adapters.
