## Context

`vendor/rails/activerecord/test/cases/arel/visitors/dot_test.rb` has 47
tests. 32 of them are generated by `define_method("test_#{klass.name…}")`
loops — 5 functions (`dot_test.rb:18-30`: Sum, Exists, Max, Min, Avg), 9
unary ops (`:39-55`: Not, Group, On, Grouping, Offset, Ordering,
UnqualifiedColumn, ValuesList, Limit), 16 binary ops (`:58-81`: Assignment,
Between, DoesNotMatch, Equality, GreaterThan, GreaterThanOrEqual, In,
LessThan, LessThanOrEqual, Matches, NotEqual, NotIn, TableAlias, As,
JoinSource, Casted), 2 nary (`:84-93`: And, Or). Each visits
`klass.new(:a, …)` through `Visitors::Dot` and passes if no error is raised.

`packages/arel/src/visitors/dot.test.ts` has the other 15 and **none of the
32** — `parity:test` reports `dot_test.rb` at 100% because the Ruby extractor
only sees `def test_…`/`it` (`scripts/test-compare/output/rails-tests.json`
lists 15 `def_test` cases for the file). See the sibling tooling story
`test-compare-blind-to-define-method-loop-tests` (RFC 0025).

Separately, every label assertion in the TS file is **weaker than Rails'**:

- `dot.test.ts:16` `'[label="<f0>BindParam"]'` vs `dot_test.rb:98`
  `'[label="<f0>Arel::Nodes::BindParam"]'` (same for CurrentRow, Distinct,
  Case, When, Else, InfixOperation, Regexp, NotRegexp, UnaryOperation, With,
  SelectCore, SelectStatement, InsertStatement, UpdateStatement,
  DeleteStatement, and `ActiveModel::Attribute::WithCastValue` →
  `WithCastValue`). Rails renders `o.class.name` (`lib/arel/visitors/dot.rb:253`);
  `packages/arel/src/visitors/dot.ts:448-449` renders the bare `ctor.name`.
- edge labels: `dot.test.ts:71` `caseSensitive`, `:120-121` `setQuantifier` /
  `optimizerHints` vs Rails `case_sensitive`, `set_quantifier`,
  `optimizer_hints` (`dot_test.rb:156,205-206`). Rails' edge name is the
  ivar name passed to `visit_edge` (`dot.rb:279`).

The assertion-value ratchet is baselined over the difference (the manifest
still holds the `Arel::Nodes::` strings), so nothing is red today.

## Acceptance criteria

- `dot.test.ts` gains the 32 generated cases as a `for…of` over the same
  class lists, naming each `it` exactly as the Ruby `define_method` would
  under the def_test convention (`"Arel Nodes Sum"` etc.), so a fixed
  extractor credits them.
- `Visitors::Dot` renders the Rails-qualified class name for arel nodes
  (`Arel::Nodes::BindParam`), matching `dot.rb:253`, and the TS assertions
  are restored to Rails' strings verbatim. If the namespace cannot be derived
  at runtime, the reason is written at `dot.ts:448` with a permanence token.
- Edge labels: either emit Rails' snake_case ivar names or record at
  `dot.ts` why the TS field name is the Rails-equivalent — one decision,
  cited, not per-assertion.
- No test renamed; `pnpm parity:test` and `parity:test:assertions` no worse.
