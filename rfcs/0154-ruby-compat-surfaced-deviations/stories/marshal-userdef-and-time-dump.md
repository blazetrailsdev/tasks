## Context

`Messages::SerializerWithFallback::MarshalWithFallback#dump` / `#_load`
(`vendor/rails/v8.0.2/activesupport/lib/active_support/messages/serializer_with_fallback.rb:63-69`)
are `Marshal.dump` / `Marshal.load`. trails' `packages/activesupport/src/messages/serializer-with-fallback.ts`
writes `"\x04\x08"` + `coder.dump` JSON instead. Swapping in ruby-compat
`Marshal` reds 29 activesupport messages tests (measured 2026-10-15):

- 10 compare with vitest `toEqual` where Rails uses `assert_equal`
  (`message-metadata-tests.ts:126` etc., `message-rotator-tests.ts:38,119,170`,
  `codec.trails.test.ts:41,47`, `serializer-with-fallback.test.ts:35`, Rails
  `serializer_with_fallback_test.rb:93-96`). `Marshal.load` answers a
  ruby-compat `Hash`, and `rbEqual` already treats it as equal to the plain
  object, so converging to `assertEqual` fixes them.
  `serializer-with-fallback.test.ts`'s `marshalModule` should be `Marshal`, as
  Rails passes.
- 19 round-trip `Time.local(2004)` (`message_metadata_tests.rb:133-137`).
  ruby-compat `Marshal.dump` writes a Time as an empty `o:\tTime\0`, because
  `w_object`'s `_dump` arm and `r_object`'s `TYPE_USERDEF` arm
  (`vendor/ruby/v3.3.11/marshal.c:916-948`, `:2186-2212`) are not ported, nor
  is `Time#_dump` / `Time._load` (`vendor/ruby/v3.3.11/time.c:5272-5605`).

`time_mdump` attaches `offset`, `zone`, `nano_num`, `nano_den` and `submicro`
as ivars on the dumped String, and `time_mload` reads them back off it.
CLAUDE.md ("Ruby Strings are JS string primitives") gives a JS string no
ivars, so the carrier for those ivars across `_dump` / `_load` is a design
decision for this story. Options considered: a boxed `String` object inside
the Marshal protocol only, or a side argument to `_load`.

Blocks `cookie-jar-serializer-fallbacks-and-legacy-cbc-upgrade`, whose cookie
tests pass `Marshal` where Rails does.

## Acceptance criteria

- `Marshal.dump` / `Marshal.load` port the `_dump` / `TYPE_USERDEF` arms.
- `Time#_dump` / `Time._load` are ported, and
  `Marshal.load(Marshal.dump(Time.local(2004)))` equals the original, checked
  against a `ruby`-generated byte fixture.
- `MarshalWithFallback` dumps and loads through ruby-compat `Marshal`, the
  `coder` path is gone, and the 29 activesupport messages tests stay green.
