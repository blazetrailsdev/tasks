## Context

Split out of `ruby-compat-has-no-marshal-for-schema-cache-and-debug` for size.
MRI's `Marshal` is `vendor/ruby/v3.3.11/marshal.c` (module `:2555`, dump
`:1207` `marshal_dump` → `w_object`, load `:2434` `marshal_load` → `r_object`),
format 4.8 (`MARSHAL_MAJOR` / `MARSHAL_MINOR`). The type list comes from what
a real schema-cache dump contains. `SchemaCache#marshal_dump`
(`vendor/rails/v8.0.2/activerecord/lib/active_record/connection_adapters/schema_cache.rb:416-418`)
is `[@version, @columns, {}, @primary_keys, @data_sources, @indexes]`:

- Integer (`@version`), `true` (`@data_sources` values), nil, and String
  (table and column names, defaults, SQL types);
- Hash of String → Array, and Array;
- `Column`, `SqlTypeMetadata` and `IndexDefinition`, which define no
  `marshal_dump` / `_dump` (checked with grep under
  `connection_adapters/`), so they are `TYPE_OBJECT` with an ivar table;
- Symbols inside those ivars (for example `SqlTypeMetadata@type`);
- repeated Strings and Symbols, which dedup into `TYPE_LINK` / `TYPE_SYMLINK`
  back-references (the cache deduplicates values, `schema_cache.rb:440-446`).

## Acceptance criteria

- [ ] `packages/ruby-compat/src/marshal.ts` exports a `Marshal` namespace with
      `dump` and `load` for: nil, true, false, Fixnum and Bignum Integer,
      Float, String (`TYPE_IVAR` with the `E` / `encoding` ivar), Symbol (a
      `":name"` string, CLAUDE.md), `TYPE_SYMLINK`, `TYPE_LINK`, Array, Hash
      (including a default), and `TYPE_OBJECT`. Objects resolve through
      `rbPathToClass` on load and are named through `rbModName` on dump.
- [ ] Any other type raises `TypeError` with MRI's message (for example
      "no \_dump_data is defined for class Proc"), both ways.
- [ ] Byte fixtures are generated by the `ruby` on PATH and checked in, and
      both directions round-trip against them.
- [ ] Citations and README rows are added.
