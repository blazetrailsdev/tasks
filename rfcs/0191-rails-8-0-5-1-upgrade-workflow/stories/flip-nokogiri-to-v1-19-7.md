## Context

Split from `bump-nokogiri-to-v1-19-7`. That PR retook the nokogiri pin floor
on `v1.18.3` (190 pairs in `scripts/api-compare/body-pins.json`) and committed
the dry run `scripts/parity/bump-ledger/reports/nokogiri-v1.18.3-v1.19.7.2026-11-22.json`.
The flip could not ride with the floor: `scripts/api-compare/lint-bump-ledger.ts:131-142`
recomputes the seed from the **base** branch's pins, and main had no nokogiri
pins, so every seeded row read "differs from the recomputed seed".

`v1.19.7` is tag `ddafea57…`, `^{}` commit `cb8cd033a3c6c67109a745f7eb4a98b05e82adbe`.
The dry run seeds 25 drift rows in 7 Ruby files (`css/parser.rb`,
`css/xpath_visitor.rb`, `html5/document.rb`, `html5/document_fragment.rb`,
`html5/node.rb`, `xml/document.rb`, …) and 4 changed-test rows in
`css/test_xpath_visitor.rb`; tests 1864 → 2034 (181 added, 11 removed, 10
changed, 50 moved); methods 248/599 → 248/610. With the seed ledgered every
gate is green (call-mismatches, body-pins and assertion ratchets red without it).

racc moves too: `vendor/nokogiri/v1.19.7/lib/nokogiri/css/parser.rb:4` says
"generated by Racc 1.8.1" (Rails' `vendor/rails/v8.0.5.2/Gemfile.lock:442`
resolves racc 1.8.1, tag `^{}` `5229883dca5b451c8bfd322272ccd2ca6d526695`).
`lib/racc/parser.rb` changes only a comment (line 22); `vendor:recite` rewrites
`packages/ruby-compat/lib/racc/parser.ts`'s citation, and
`scripts/api-compare/class-paths.ts:648-649` cite `racc/v1.8.0` by hand.
