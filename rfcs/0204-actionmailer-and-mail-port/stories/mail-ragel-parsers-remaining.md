## Context

The other eleven `vendor/mail/2.8.1/lib/mail/parsers/*.rb` files (content type, disposition,
location, transfer encoding, date-time, envelope-from, message ids, mime version,
phrase lists, received), run through the spike's script.

## Acceptance criteria

- Every parser generated by the script, each citing its `.rl` source.
- A CI step re-runs the script over the vendored gem and fails on any diff.
- `spec/mail/parsers/*_spec.rb` pass.
- Generated output exceeds the PR LOC ceiling; the PR body asks the repo owner for
  the waiver, as the RFC's "Generated parsers and the LOC ceiling" records.
