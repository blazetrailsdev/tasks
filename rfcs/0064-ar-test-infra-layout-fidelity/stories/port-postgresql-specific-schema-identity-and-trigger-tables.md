## Context

Follow-up to `port-postgresql-specific-schema-remainder`, which ported the
plain `create_table` half of
`vendor/rails/activerecord/test/schema/postgresql_specific_schema.rb:50-225`
into `loadPostgresqlSpecificSchema`
(`packages/activerecord/src/support/load-schema-helper.ts`):
`postgresql_times`, `postgresql_oids`, `limitless_fields`, `bigint_array`,
`uuid_comments`/`uuid_entries`/`uuid_items`/`uuid_messages`,
`test_exclusion_constraints`, `test_unique_constraints`.

Still unported from that file: the two raw-DDL identity tables, gated on
`supports_identity_columns?` — schema.rb lines 50-66:

```ruby
drop_table "postgresql_identity_table", if_exists: true
execute "create table postgresql_identity_table (id INT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY)"
drop_table "cpk_postgresql_identity_table", if_exists: true
execute "create table cpk_postgresql_identity_table (another_id INT NOT NULL, id INT NOT NULL GENERATED BY DEFAULT AS IDENTITY, CONSTRAINT cpk_postgresql_identity_table_pkey PRIMARY KEY (another_id, id))"
```

and the trigger-populated PK table, gated on `supports_insert_returning?` —
lines 203-225 (`pk_autopopulated_by_a_trigger_records` plus the
`populate_column()` plpgsql function and `before_insert_trigger`).

Both are laid inline today by sibling suites that must be repointed at the
boot-laid tables in the same change:

- `packages/activerecord/src/persistence.test.ts:1994-2012` —
  `postgresql_identity_table`.
- `packages/activerecord/src/persistence.test.ts:2050-2110` —
  `pk_autopopulated_by_a_trigger_records` + `populate_column()`. Note this
  suite runs the MariaDB arm too, so only the PG arm can be repointed.
- `packages/activerecord/src/dirty.test.ts:1203-1223` —
  `cpk_postgresql_identity_table`.

## Acceptance criteria

- `loadPostgresqlSpecificSchema` lays `postgresql_identity_table` and
  `cpk_postgresql_identity_table` under a `supportsIdentityColumns()` gate, and
  `pk_autopopulated_by_a_trigger_records` + `populate_column()` +
  `before_insert_trigger` under a `supportsInsertReturning()` gate, matching
  the Rails DDL verbatim.
- All three tables are listed in `ADAPTER_SPECIFIC_TABLES` in the same file, or
  `support/drop-all-tables.ts`'s between-test reset drops them.
- The inline layers in `persistence.test.ts` (PG arm) and `dirty.test.ts` are
  repointed at the boot-laid tables.
