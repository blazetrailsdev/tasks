## Context

`define-column-methods-writes-abstract-prototype-not-receiver` made
`TableDefinition.defineColumnMethods` (`packages/activerecord/src/connection-adapters/abstract/schema-definitions.ts`)
a faithful port of `ColumnMethods.define_column_methods`
(`activerecord/lib/active_record/connection_adapters/abstract/schema_definitions.rb:332-341`):
it defines on the receiver's prototype unconditionally, with the Rails body. The
abstract list (`schema_definitions.rb:324-328`, including the `blob`/`numeric`
aliases) is now generated by calling it at module scope, and `TableDefinition`
merges `interface TableDefinition extends ColumnMethods` for the types.

Two lists are still hand-written, which PR scope left out:

- **PostgreSQL** `TableDefinition`
  (`packages/activerecord/src/connection-adapters/postgresql/schema-definitions.ts`, the
  `bigserial` … `xml` methods plus the private `definedPgColumn` helper). Rails generates
  them with `define_column_methods :bigserial, :bit, :bit_varying, … :timestamptz, :enum`
  in `PostgreSQL::ColumnMethods`' `included do`
  (`postgresql/schema_definitions.rb:185-188`).
- **MySQL** `TableDefinition` and the `unsigned_*` / `*blob` / `*text` methods
  (`packages/activerecord/src/connection-adapters/mysql/schema-definitions.ts`), from
  `mysql/schema_definitions.rb:46-51`, including
  `deprecate :unsigned_float, :unsigned_decimal`.

The `Table` (change_table) side is separate: abstract/PG/MySQL `Table` column methods
are `async` because `Table#column` awaits an `ALTER`, so the synchronous generated body
cannot be shared as-is. `Table#definedColumn` (abstract) stays for them.

## Acceptance criteria

- `PostgreSQL::TableDefinition` and `MySQL::TableDefinition` generate their column
  methods by calling `defineColumnMethods` with Rails' lists, typed through a merged
  interface (the adapter `ColumnMethods` interfaces already exist), and
  `definedPgColumn` / the hand-written methods are deleted.
- MySQL's `unsignedFloat` / `unsignedDecimal` keep the deprecation warning
  (`mysql/schema_definitions.rb:50`).
- `Table`'s async column methods either reuse the generator (via an async variant
  matching `Table#column`) or stay, with the reason recorded here.
- `pnpm parity:api:extra:gate`, `pnpm parity:api:calls` stay green.
