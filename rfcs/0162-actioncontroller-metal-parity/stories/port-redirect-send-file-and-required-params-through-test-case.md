## Context

Split out of `port-redirect-send-file-and-metal-remainders`, whose PR shipped
only the `metal_test.rb` half: the bundle it rode in used the LOC ceiling on
deletions. Three files under
`vendor/rails/v8.0.2/actionpack/test/controller/` are still partly ported.

`redirect_test.rb` → `packages/actionpack/src/action-controller/controller/redirect.test.ts`
(`pnpm parity:test`: 39 matched, 14 missing, 11 extra):

- Missing, all in `RedirectTest`: `test_redirect_to_record` (`:415`),
  `test_polymorphic_redirect` (`:435`),
  `test_polymorphic_redirect_with_string_args` (`:453`),
  `test_redirect_to_with_block` (`:486`),
  `test_redirect_to_with_block_and_assigns` (`:492`),
  `test_redirect_to_out_of_scope_block` (`:498`),
  `test_redirect_to_with_block_and_accepted_options` (`:504`),
  `test_unsafe_redirect_with_malformed_url` (`:539`),
  `test_unsafe_redirect_with_protocol_relative_double_slash_url` (`:549`),
  `test_unsafe_redirect_with_protocol_relative_triple_slash_url` (`:559`),
  `test_unsafe_redirect_with_illegal_http_header_value_character` (`:569`),
  `test_url_from` (`:590`), `test_url_from_fallback` (`:598`),
  `test_redirect_to_instrumentation` (`:610`).
- Extra, with no Rails counterpart: `redirect_to with path`,
  `redirect_to with full URL`, `redirect_to with 301`,
  `redirect_to with see_other`, `redirect_to marks as performed`,
  `redirect_back uses referer`, `redirect_back uses fallback when no referer`,
  `redirect_back with custom status`, `redirect then redirect throws`,
  `redirect in before_action prevents action`,
  `redirect body contains escaped html`.
- The file has no `RedirectController` (`redirect_test.rb:29-221`) and no
  `Workshop` (`:5-27`). Its matched tests call the free `redirectTo` /
  `redirectBack` from `action-dispatch/redirect.js` instead of
  `get :simple_redirect` through `ActionController::TestCase`, which is why the
  file carries 34 assertion mismatches. The missing tests cannot be written
  against that shape: they need `with_routing`, `assert_redirected_to` with a
  record, and `with_raise_on_open_redirects` (`:632-638`).
  `controller/action-pack-assertions.test.ts` is the pattern
  (`new TestCase(task.name)`, `tc.controller = new …`, `await tc.beforeSetup()`,
  `tc.withRouting`, `tc.assertRedirectedTo`).
- Production code the missing tests reach, in
  `action-controller/metal/redirecting.ts`: the `Proc` arm of
  `_compute_redirect_to_location`
  (`actionpack/lib/action_controller/metal/redirecting.rb:170`), which
  `instance_eval`s the block, so `OUT_OF_SCOPE_BLOCK` (`redirect_test.rb:9-12`)
  must see the controller as `self`; `_url_host_allowed?` for
  `"http:///www.rubyonrails.org/"`; and
  `"Please use symbols for polymorphic route arguments."`
  (`actionpack/lib/action_dispatch/routing/polymorphic_routes.rb:304,319`).

`send_file_test.rb` → `controller/send-file.test.ts` (24 matched, 8 missing,
1 extra):

- Missing: `test_send_file_instrumentation` (`:210`),
  `test_send_data_instrumentation` (`:226`), and the six generated by

`required_params_test.rb` → `controller/required-params.test.ts` (11 matched,
1 missing):

- Missing: `exceptions have suggestions for fix` (`:25-35`), which asserts
  `error.detailed_message` matches `"Did you mean?"`.
- `ParameterMissing` (`action-controller/metal/strong-parameters.ts:34-55`) has
  `corrections` but no `detailed_message`: Rails' class does
  `include DidYouMean::Correctable`
  (`actionpack/lib/action_controller/metal/strong_parameters.rb:33-39`), and
  `@blazetrails/did-you-mean` has no `Correctable`
  (`vendor/ruby/v3.3.11/lib/did_you_mean/core_ext/name_error.rb:2`). Thor's
  local `Correctable` (`packages/trailties/src/thor/error.ts:9-20`) and the
  `withCorrections` helper in
  `packages/activerecord/src/associations/errors.ts:6-9` are the two existing
  stand-ins.
- The file has no `BooksController` (`:5-10`); its
  `ActionControllerRequiredParamsTest` tests call `Parameters#require` directly
  instead of `post :create`.

## Acceptance criteria

- Every missing test above is ported in Rails order under its Rails class,
  driven through the Rails controller (`RedirectController`,
  `SendFileController`, `BooksController`) and `ActionController::TestCase`.
- The extra tests are deleted as duplicates or moved to a `.trails.test.ts`
  sibling.
- `ParameterMissing#detailed_message` comes from a ported
  `DidYouMean::Correctable`, not a local helper.
- `pnpm parity:test` reports the three files with nothing missing and no extra,
  apart from the six `SendFileController#test_send_file_headers_*` action rows
  (`send_file_test.rb:31-67`) the extractor counts as tests.
- New code has no `node:*` import and no synchronous `fs` call.
