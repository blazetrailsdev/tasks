## Context

`pnpm parity:fixtures`: 146 files — match 137, **diff 6**, erb-allowed 3; schema ported **113/143**.

- DIFF: `all/namespaced/accounts.yml` (0/1 attrs), `books.yml` (27/28), `dead_parrots.yml` (3/4),
  `live_parrots.yml` (2/3), `naked/yml/parrots.yml` (0/2), `to_be_linked/users.yml` (3/7).
- schema not ported (fixture sets whose table is absent from `TEST_SCHEMA`): `admin/randomly_named_*`,
  `aircrafts`, `bad_posts`, `categories/special_categories`, `categories/subsubdir/arbitrary_filename`,
  `categories_ordered`, `colleges`, `courses`, `dead_parrots`, `encrypted_book_that_ignores_cases`,
  `fk_object_to_point_to`, `live_parrots`, `naked/yml/*`, `other_books`, `other_comments`, `other_dogs`,
  `other_posts`, `other_topics`, `primary_key_error`, `randomly_named_a9`, `reserved_words/*` (5),
  `uuid_children`, `uuid_parents`, `virtual_columns`. Several map to tables schema.rb does declare
  under another name (the fixture's `_fixture: model_class:`), which the comparer must follow.
- ERB-allowed: `citations.yml`, `mixins.yml`, `paragraphs.yml` are generated by ERB loops in Rails;
  trails spells ERB as TSE, so they are portable through the TSE compiler.

## Acceptance criteria

- [ ] The six DIFF files match Rails' rows and attributes.
- [ ] The comparer resolves each fixture set's table as `FixtureSet#initialize` does (`fixtures.rb:713-722`),
      and every set whose table a Rails `test/schema/*.rb` file declares is in the canonical schema: schema
      ported N/N over those sets. A set whose table no schema file declares — the test creates it
      (`reserved_words/*`, `virtual_columns`, `other_topics`) or Rails never loads the set
      (`all/namespaced/accounts`, `naked/yml/courses_with_invalid_key`) — is reported as
      `schema:no-rails-table` and has nothing to port; adding those tables would be invented schema that
      `parity:schema` rejects.
- [ ] The comparer renders the three ERB fixtures' Rails templates through the TSE compiler and compares
      them row for row with Rails' row counts (65536 / 1001 / 20); erb-allowed 0. The TS fixture modules
      stay as loops: rendering and YAML-parsing 65536 rows at module load would cost every worker that
      imports the fixtures registry.
- [ ] `pnpm parity:fixtures`: diff 0, erb-allowed 0.
