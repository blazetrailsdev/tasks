## Context

Third follow-up in the metaprogrammed-surface line, after
`extractor-capture-metaprogrammed-ruby-surface` (class_attribute / alias /
delegate) and `extractor-capture-enumerable-metaprogrammed-surface`
(Relation VALUE_METHODS) — both done. The remaining uncaptured pattern is the
plain `define_method` loop.

`scripts/api-compare/extract-ruby-api.rb` records only literal `def`s, so a
method generated by iterating a list and calling `define_method` is invisible to
the allow-set and every faithful TS port of it reads as novel drift.

Live instances, all currently carrying allowlist entries in
`scripts/api-compare/extra-surface-allow.json`:

- `abstract_controller/callbacks.rb` — `[:before, :after, :around].each do |cb|
define_method "#{cb}_action" … end` plus the `skip_*` forms. Costs **12**
  allowlist entries: 6 on `callbacks.ts` for the definitions and 6 on `base.ts`
  for the mixin install sites.
- `abstract/schema_definitions.rb:324` — `define_column_methods` generating the
  `ColumnMethods` list. Costs **3** entries for `columnMethodNames` on
  abstract / mysql / postgresql adapters.

That is 15 of the 45 allowlist entries — a third of the file — traceable to one
extractor gap.

The generated names are string-interpolated, so a general solution is not
possible; capture the enumerated-literal-receiver case
(`[:a, :b].each { define_method "#{x}_suffix" }` and `define_column_methods
:type, :type, …`) and leave genuinely dynamic receivers alone rather than
guessing.

## Acceptance criteria

- The extractor records methods generated by `define_method` inside an `each`
  over a literal symbol/array receiver, and by `define_column_methods`.
- Names appear in `rails-api.json` attributed to the declaring file so both
  `collectAllowedNames` and `buildGlobalRubyCandidates` see them.
- A dynamic receiver the extractor cannot resolve is skipped silently, not
  guessed at.
- Tests in `scripts/api-compare/extract-ruby-api.test.ts`.
- Delete the allowlist entries the fix makes stale (the 12 abstractcontroller
  callback entries and the 3 `columnMethodNames` entries) and record the
  novel-count delta.
