## Context

`trails generate benchmark` (trails#9935) adds `benchmark-ips` as a devDependency and emits a script calling `Benchmark.ips((x) => { x.report(...); x.compare(); })`, mirroring Rails' `benchmark.rb.tt` (`vendor/rails/v8.0.2/railties/lib/rails/generators/rails/benchmark/templates/benchmark.rb.tt`). No trails port of the benchmark-ips gem exists (ruby-compat's `Benchmark` in `packages/ruby-compat/lib/benchmark.ts` has only `realtime`), so the generated script's `import { Benchmark } from "benchmark-ips"` does not resolve.

## Acceptance criteria

- A `benchmark-ips` package ports `Benchmark.ips`, `Benchmark::IPS::Job#report` and `#compare!` (as `compare`) from the benchmark-ips gem, vendored first.
- A script generated by `trails generate benchmark` runs against it.
