# RFC — Rails 8.0.5.2 burn-down

## Summary

The Rails source of truth moved from `v8.0.2` to `v8.0.5.2` under RFC 0191
(`0191-rails-8-0-5-1-upgrade-workflow`), with every drifted or removed body pin
and every changed test parked in the bump ledger
(`scripts/parity/bump-ledger/rails.json`, `rails.tests.json` in trails). This
RFC holds the stories that empty that ledger, one per package or subsystem.

## Motivation

A ledger row is a body the port has not re-verified against the new Rails.
Until each is re-read, re-ported where it changed, and re-pinned, the gates
skip it, and the tests upstream added in the bump are unported.

## Design

Every story here is generated, not hand-written, by
`scripts/parity/bump-dry-run/generate-stories.ts` in trails, run as

```sh
pnpm parity:bump:stories --source rails --from v8.0.2 --to v8.0.5.2 \
  --from-tests <rails-tests.json extracted at v8.0.2> \
  --rfc 0000-rails-8-0-5-2-burn-down --out rfcs/0000-rails-8-0-5-2-burn-down/stories \
  --config scripts/parity/bump-ledger/rails.stories.json
```

Each story lists, per Ruby file it owns, the `git diff --no-index` between
the two vendored versions, the TS file, its ledger rows, and the added,
removed and changed upstream tests of its test files. Its acceptance criteria
end in a `body-pins.ts --pin` per Ruby file, no ledger row left in its files,
and every added test ported or recorded as not ported with its reason.

A package over 15 Ruby files is split along subsystem directories
(`rails.stories.json`), never below one file. Stories depend on every story of
the package before them, in the order arel, activemodel, activesupport,
activerecord, actionpack, actionview, actioncable, activejob, activestorage,
actionmailbox, actiontext, trailties (actionmailer has no ledger rows, so it
has no story and drops out of the chain). Inside actionpack,
`rails-8-0-5-2-actioncontroller` comes first and the three
`actiondispatch-*` stories depend on it. The actionview story
owning `sanitize_helper.rb` and `text_helper.rb` also depends on
`bump-rails-html-sanitizer-to-v1-7-2`.

## Non-goals

- Rails 8.1: its own bump, generated by the same script.
- **Hand-editing the stories:** rerun the generator against the current ledger.
- **actionmailer:** no ledger rows or test changes in the bump, so nothing to burn down.
- **Gem bumps the new Rails requires:** owned by RFC 0191 (e.g.
  `bump-rails-html-sanitizer-to-v1-7-2`); this RFC only depends on them.

## Alternatives considered

- **One story per Ruby file:** hundreds of tiny PRs, each re-running the same
  package gates; a package or subsystem is the smallest unit a reviewer can
  check against the ledger in one sitting.
- **Hand-written stories:** drift from the ledger the moment it changes; the
  generator keeps the ledger the single authority.
- **Parallel stories (no package chain):** a downstream package re-verified
  before its upstream would pin bodies against behavior that is still moving.
  The chain follows the Rails dependency order; stories within one package
  share deps and can run in parallel.

## Rollout

Each phase is one package; stories inside a phase run in parallel.

1. arel: `rails-8-0-5-2-arel`
2. activemodel: `rails-8-0-5-2-activemodel`
3. activesupport: `rails-8-0-5-2-activesupport-cache`,
   `rails-8-0-5-2-activesupport-core-ext`, `rails-8-0-5-2-activesupport-other`
4. activerecord: `rails-8-0-5-2-activerecord-associations`,
   `rails-8-0-5-2-activerecord-connection-adapters`,
   `rails-8-0-5-2-activerecord-core-and-attributes`,
   `rails-8-0-5-2-activerecord-migrations-and-schema`,
   `rails-8-0-5-2-activerecord-relation-and-query`
5. actionpack: `rails-8-0-5-2-actioncontroller`, then
   `rails-8-0-5-2-actiondispatch-http`, `rails-8-0-5-2-actiondispatch-other`,
   `rails-8-0-5-2-actiondispatch-routing`
6. actionview: `rails-8-0-5-2-actionview-helpers`,
   `rails-8-0-5-2-actionview-rendering`,
   `rails-8-0-5-2-actionview-sanitizer-helpers` (also after
   `bump-rails-html-sanitizer-to-v1-7-2`)
7. actioncable: `rails-8-0-5-2-actioncable`
8. activejob: `rails-8-0-5-2-activejob`
9. activestorage: `rails-8-0-5-2-activestorage`
10. actionmailbox: `rails-8-0-5-2-actionmailbox`
11. actiontext: `rails-8-0-5-2-actiontext`
12. trailties: `rails-8-0-5-2-trailties`

## Verification

- `scripts/parity/bump-ledger/rails.json` and `rails.tests.json` hold zero
  rows for the v8.0.2 → v8.0.5.2 bump.
- Every Ruby file named in the 23 stories is re-pinned by `body-pins.ts --pin`
  at v8.0.5.2, and the body-pin gate passes with no ledger skips.
- Every upstream test added in the bump is ported or recorded as not ported
  with its reason.
